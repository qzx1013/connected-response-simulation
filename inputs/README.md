# Fixed reference inputs

Both files are included in the repository, not fetched from a private server.

- `0522_reference_data.pt`: the existing 16-qubit gate/channel reference used by Figures 3 and 4. It contains the original circuit pattern and tensor data. The residual Hamiltonian is taken from the new packaged manifest, not inferred from this older filename.
- `qutrit_kraus.pt`: the matched 4×4, T1 = T2 = 5 μs, piece_num = 1000 local qutrit Kraus cache. It is independent of the residual pair selection. The loader checks its channel construction settings.

`sha256.json` fixes the original bytes. `residual-tn validate` checks them. These files contain numerical data, not remote access credentials or private Python classes. Checkpoints generated by a run belong under its output directory and are not input assets for GitHub.
